## 1. 快速开始

页面底部出现毛玻璃风格的主终端栏，逐字打印欢迎信息：

```
# YeQuDesu · Personal Site · ready
```

约 2 秒后打字机完成 + 1.5 秒 exit gap，终端进入**等待状态（idle）**。此时：

- **按 `/` 键** — 激活终端，开始输入命令
- **点击终端栏任意位置** — 同上

输入 `help` 然后按 **Enter** 查看所有可用命令。

Act 3（滚动到 85% 后）左上角会出现**信息面板终端**，实时显示 3D 场景运行数据。

## 2. 终端实例

项目包含两个终端实例，均基于同一引擎（TerminalBar）：

### 2.1 主终端（MainTerminal）

| 属性 | 值 |
|------|-----|
| 位置 | 页面底部居中 |
| 激活 | 点击终端栏 或 按 `/` 键 |
| 功能 | 命令交互（help / debug / day / night / clear） |
| 显示 | 欢迎文本 + 实时状态行（Act / scroll%） |

### 2.2 信息面板终端（InfoPanelTerminal）

| 属性 | 值 |
|------|-----|
| 位置 | Act 3 左上角（scrollProgress ≥ 85%） |
| 激活 | 仅点击 |
| 功能 | 实时显示 3D 场景数据（只读） |
| 显示 | 行星坐标 + 轨道参数 + 摄像机状态 + debris 计数 |

## 3. 激活与退出

### 3.1 主终端

| 操作 | 效果 |
|------|------|
| 按 `/` 键 | 立即激活（typing 期间无效，其他输入框中无效） |
| 点击终端栏 | 同上 |
| 按 **Esc** | 退出 active → idle，清空输入 |
| 点击页面其他区域 | 100ms 后退出 |

### 3.2 信息面板终端

| 操作 | 效果 |
|------|------|
| 点击终端栏 | 激活，可滚动查看内容 |
| 点击外部 | 退出 |

### 3.3 状态流转

```
typing（打字机）→ idle（等待）↔ active（活跃）
```

- **typing**：页面加载自动进入，~3.9 秒（typewriter + exitGap）。无法手动激活。
- **idle**：显示欢迎信息 + 实时状态行。主终端光标常亮。
- **active**：`$` 提示符 + 闪烁光标 + placeholder。**页面滚动被阻止**（主终端）。

## 4. 命令参考

### 4.1 内置命令

| 命令 | 别名 | 说明 |
|------|------|------|
| `help` | — | 列出所有可用命令 |
| `debug` | — | 切换调试模式（`window.__DEBUG__`） |
| `day` | `light` | 切换到日间模式 |
| `night` | `dark` | 切换到夜间模式 |
| `clear` | `cls` | 清空回显区 |

### 4.2 命令输出

命令输出通过声明式 Section slot 渲染，支持 `rows: 'lineByLine'` 逐行揭示动画。

`clear` 只清空命令输出区域，不影响欢迎文本和状态行。

## 5. 交互指南

### 5.1 键盘操作（主终端）

| 按键 | 状态 | 效果 |
|------|------|------|
| `/` | idle | 激活终端 |
| 任意字符 | active | 输入命令文本 |
| **Enter** | active | 执行命令 |
| **Esc** | active | 退出 → idle，清空输入 |
| **ArrowUp** | active | 回显区向上滚动 |
| **ArrowDown** | active | 回显区向下滚动 |

### 5.2 鼠标/触控

| 操作 | 状态 | 效果 |
|------|------|------|
| 点击终端栏 | idle | 激活 |
| 鼠标滚轮在回显区 | active | 滚动回显区 |
| 点击外部 | active | 100ms 后退出 |

### 5.3 回显区滚动 + pinnedToBottom

- 新内容到达时，仅在用户在底部时自动跟随滚动
- 用户向上滚动查看历史 → 自动跟随暂停 → 滚回底部恢复
- **▲ / ▼ 指示器**：内容超出可见区域时显示

## 6. 视觉反馈说明

### 6.1 打字机入场 + exitGap

欢迎信息逐字打印。完成后光标继续闪烁 **exitGap**（主终端 1.5s，信息面板 1.0s），作为与后续内容的视觉过渡。

### 6.2 状态行

```
# Act 1 · OceanVoyage · scroll 34%
```

实时反映页面位置。Act 编号随滚动自动切换。

### 6.3 颜色过渡

终端文字颜色随 Act 1→Act 2 白化过程平滑过渡（`scrollProgress 0.40–0.55`，smoothstep 曲线）。

### 6.4 光标状态

| 光标 | 场景 |
|------|------|
| 打字机光标 | typing 态，1s 闪烁 |
| dim 光标 | idle 态，天蓝色常亮 |
| bright 光标 | active 态，白色 1s 闪烁 |

## 7. 故障排除

### Q: 按 `/` 没有反应？

- 打字机动画未完成（~3.9 秒内）。等待结束。
- 焦点在输入框中。点击页面空白区域后重试。

### Q: 页面无法滚动？

- 终端处于 active 态。按 Esc 退出。
- Act 3 聚焦时滚动也被阻止。

### Q: 信息面板终端不显示？

- 需滚动到 Act 3（85% 之后）才会出现。
