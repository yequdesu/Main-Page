## 1. 快速开始

打开页面后，你会看到底部出现一个毛玻璃风格的终端栏，逐字打印欢迎信息：

```
# YeQuDesu · Personal Site · ready
```

约 2 秒后打字机完成，终端进入**等待状态（idle）**。此时可以：

- **按 `/` 键** — 激活终端，开始输入命令
- **点击终端栏任意位置** — 同上

输入 `help` 然后按 **Enter** 查看所有可用命令。

## 2. 激活与退出

### 2.1 激活方式

| 操作 | 效果 | 备注 |
|------|------|------|
| 按 `/` 键 | 立即激活，光标开始闪烁 | 打字机动画期间无效 |
| 点击终端栏 | 同上 | 点击 bar 任意位置均可 |

**限制：** 当你在其他输入框（如表单、搜索框）中输入时，按 `/` 不会激活终端。

### 2.2 退出方式

| 操作 | 效果 |
|------|------|
| 按 **Esc** | 立即退出 active，回到 idle 态，清空输入 |
| 点击页面其他区域 | 100ms 后退出（允许误触恢复） |

### 2.3 状态流转

```
typing（打字机）→ idle（等待）↔ active（活跃）
```

- **typing 态**：页面加载时自动进入，约 2.4 秒后自动结束。此状态下无法手动激活终端。
- **idle 态**：显示欢迎信息 + 实时页面状态行。终端栏半透明，光标常亮但不闪烁。
- **active 态**：显示 `$` 提示符 + 输入光标 + placeholder。光标闪烁，可输入命令。**页面滚动被阻止**。

## 3. 命令参考

### 3.1 内置命令

| 命令 | 别名 | 说明 | 输出示例 |
|------|------|------|----------|
| `help` | — | 列出所有可用命令 | 表格形式的命令列表 |
| `debug` | — | 切换调试模式 | `debug mode: ON` / `debug mode: OFF` |
| `day` | `light` | 切换到日间模式 | `switched to day mode` |
| `night` | `dark` | 切换到夜间模式 | `switched to night mode` |
| `clear` | `cls` | 清空回显区 | 回显区重置为初始欢迎信息 |

### 3.2 help 命令输出

```
Available commands:
  help     Show available commands
  debug    Toggle debug mode
  day      Switch to day mode
  night    Switch to night mode
  clear    Clear the echo area
```

### 3.3 debug 命令

切换 `window.__DEBUG__` 全局标志。当前项目未在 UI 中使用此标志，可用于开发调试脚本：

```js
// 浏览器 DevTools Console
console.log(window.__DEBUG__)  // true / false
```

### 3.4 day / night 命令

控制 `<html>` 元素的 CSS class：

```
day   → <html class="light">   （移除 .dark）
night → <html class="dark">    （移除 .light）
```

当前项目在 `index.html` 中设置了默认 `<html class="dark">`，因此初始为夜间模式。主题切换的具体视觉效果取决于项目中配套的 CSS 变量定义。

### 3.5 clear 命令

`clear`（或 `cls`）将回显区重置为初始欢迎信息 + 当前状态行。终端保持 active 模式（不退出、不丢焦点），用户可以继续输入下一条命令。这与传统终端的 "clear" 行为略有不同——保留了状态行以便用户继续看到页面信息，且保持了输入连续性。

### 3.6 未知命令

输入未注册的命令时，终端会显示错误提示：

```
command not found: xxxxxx
Type 'help' for available commands
```

## 4. 交互指南

### 4.1 键盘操作

| 按键 | 状态 | 效果 |
|------|------|------|
| `/` | idle | 激活终端 |
| 任意字符 | active | 输入命令文本 |
| **Enter** | active | 执行命令 |
| **Esc** | active | 退出 active → idle，清空输入 |
| **ArrowUp** | active | 回显区向上滚动一行 |
| **ArrowDown** | active | 回显区向下滚动一行 |

### 4.2 鼠标/触控操作

| 操作 | 状态 | 效果 |
|------|------|------|
| 点击 bar 任意位置 | idle | 激活终端 |
| 拖拽回显区滚动条 | active | 滚动回显区（仅内容溢出时） |
| 鼠标滚轮在回显区 | active | 滚动回显区 |
| 点击 bar 外部 | active | 100ms 后退出（若焦点未恢复） |

### 4.3 输入行为

- **实时回显：** 输入的文本实时显示在 `$` 提示符右侧
- **placeholder 提示：** 输入为空时显示 `type 'help' for available commands`
- **没有历史：** 当前版本不支持命令历史回溯（ArrowUp 用于滚动回显区，而非历史命令）
- **没有自动补全：** 当前版本不支持 Tab 补全
- **大小写敏感：** 命令名区分大小写（`Help` ≠ `help`）

### 4.4 回显区滚动

当回显区内容超过 5 行时：

- **▲ 指示器** 出现在回显区顶部（表示上方有更多内容）
- **▼ 指示器** 出现在回显区底部（表示下方有更多内容）
- 指示器平滑淡入淡出（0.15s transition）
- **ArrowUp / ArrowDown** 以行为单位滚动

## 5. 视觉反馈说明

### 5.1 状态行

idle 态下，回显区中始终有一行以 `#` 开头、实时反映当前页面位置的状态信息：

```
# Act 1 · OceanVoyage · scroll 34%
```

**内容格式：** `# Act {1|2|3} · {ActName} · scroll {percent}%`

- Act 编号和名称随滚动进度自动切换（Act 1: 0–45%，Act 2: 45–85%，Act 3: 85–100%）
- 百分比四舍五入到整数，随页面滚动实时刷新

**位置：** 状态行始终位于回显区末尾。当有命令输出时，输出追加在状态行之前；`clear` 后状态行重新出现。它由独立于 echo 内容的更新逻辑维护——不会被命令输出覆盖或冲掉。

**暂停更新的情况：** active 态执行命令且回显动画播放中（输出逐行显示时），状态行暂停更新。原因：回显动画逐行替换文本本身带有视觉变化，状态行同步更新会造成两种动画互相干扰。动画完成后状态行恢复更新。

### 5.2 光标状态

| 光标样式 | 出现场景 | 视觉效果 |
|----------|----------|----------|
| 打字机光标 | typing 态 | 紧跟打字机文本后，1s 闪烁 |
| dim 光标 | idle 态，输入为空 | 紧跟 `$` 后，常亮，天蓝色 |
| bright 光标 | active 态，输入为空 | 紧跟 `$` 后，1s 闪烁，白色 |
| 输入文本 | active 态，有输入 | 替换光标位置显示输入文本 |

### 5.3 颜色过渡

Terminal Bar 的文字颜色会随页面 3D 场景的**白化过程**（Act 1 → Act 2）平滑过渡：

- **Act 1（暗色背景）：** 文字偏亮（`#e2e8f0`），确保深色背景上的可读性
- **Act 2 白化中：** 文字逐渐变暗
- **Act 3（亮色背景）：** 文字偏暗（`#1e293b`），确保亮色背景上的可读性

过渡范围在 `scrollProgress` 的 0.40 到 0.55 之间，使用 smoothstep 曲线确保平滑。

### 5.4 毛玻璃效果

- 终端面板下方的内容（3D 场景）实时透过
- `backdrop-filter: blur(20px)` 产生模糊效果
- `saturate(180%)` 增强色彩饱和度
- Act 1 暗色场景下效果明显，Act 3 亮色场景下较微弱

## 6. 常见操作场景

### 6.1 查看可用命令

```
/ → help → Enter
```

### 6.2 切换日间/夜间模式

```
/ → day → Enter    （切换到日间模式）
/ → night → Enter  （切换回夜间模式）
```

### 6.3 开启调试模式

```
/ → debug → Enter
```

再次执行 `debug` 关闭。

### 6.4 清空回显区

```
/ → clear → Enter
```

回显区恢复到初始欢迎信息。

### 6.5 终端激活时临时滚动回显区

按 `/` 激活终端后，用 **ArrowUp / ArrowDown** 或鼠标拖拽滚动条查看回显区历史内容。按 **Esc** 或点击外部区域退出，恢复页面滚动。

## 7. 故障排除

### Q: 按 `/` 没有反应？

- **原因 1：** 打字机动画尚未完成（页面加载后约 2.4 秒内）。等待动画结束即可。
- **原因 2：** 焦点在输入框中（如浏览器地址栏）。点击页面空白区域后再试。
- **原因 3：** 浏览器扩展拦截了 `/` 键。尝试在无痕窗口中打开。

### Q: 输入命令后按 Enter 没反应？

- 检查是否在 active 态（`$` 提示符和闪烁光标可见）
- 检查输入是否正确（命令名区分大小写）
- 尝试输入 `help` 验证终端是否正常工作

### Q: 页面无法滚动？

- 检查终端是否处于 active 态（`$` 提示符可见）
- 按 **Esc** 或点击页面其他区域退出 active
- active 态下页面滚动被有意阻止，防止终端输入时意外滚动

### Q: 终端显示不正常（无毛玻璃效果）？

- 确认浏览器支持 `backdrop-filter`（Chrome 90+, Safari 15+）
- 检查浏览器是否启用了硬件加速
- 终端下方需要 3D 场景内容才能看到毛玻璃效果（在纯白/纯黑背景上不可见）

### Q: 终端文字看不清？

- 3D 场景过亮或过暗时，文字颜色会自动调整
- 如果效果不理想，可用 `day` / `night` 命令手动切换主题

### Q: ▲/▼ 指示器不显示？

- 需要回显区内容超过 5 行（约 5 条命令输出）
- 仅在 active 态下可滚动（idle 态 `overflow: hidden`）
- 多次执行 `help` 命令积累输出后检查
