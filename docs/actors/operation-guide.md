## 2. CentralStar 外观

### 正常状态

恒星呈现暖金色调，从中心向外有 4 层视觉效果：

1. **明亮的暖白核心** — 最内层实体球
2. **金色内层光晕** — 近场散射，轻微脉冲呼吸
3. **金色近场柔光** — 较大范围的渐变光晕
4. **灰白远场柔光** — 最大范围的扩散柔光（范围约近场的 3 倍）

所有光晕叠加 AdditiveBlending（叠加混合），在暗色背景上呈现自然发光效果。

### 脉冲动画

恒星光晕以约 1.8Hz 的频率缓慢呼吸，叠加 3.3Hz 的高频微抖。亮度在 ±6% 范围内波动，模拟真实恒星的亮度变化。

### 出现时机

恒星在 Act 3（滚动位置 ≥ 85%）时随 `smooth3` 渐进出现。进入 Act 3 前不可见。

## 3. Planets 外观

### 正常状态

每颗行星呈现灰白冷色调，4 层结构：

1. **灰白核心** — 颜色随滚动位置从冷白过渡到灰蓝
2. **内层光晕** — 灰白透明球，轻微脉冲呼吸，明确光晕边界
3. **Fresnel 边缘辉光** — 视角相关辉光（摄像机看向行星边缘时更明显）
4. **Sprite 远场柔光** — 扩散光晕，AdditiveBlending

### 视角相关效果

- **正面看行星**：Fresnel 辉光较淡
- **侧面/边缘看行星**：Fresnel 辉光更明显（边缘发光效应）

这是 `AtmosphereShader` 的 `dot(normal, viewDirection)` 计算实现的：边缘处点积趋于 0 → Fresnel 因子趋于 1 → 辉光最亮。

### 聚焦效果

点击行星 → 相机靠近聚焦：

- 聚焦行星：光晕正常显示
- 非聚焦行星：所有光晕跟随核心 opacity 自动淡出（减少视觉干扰）
- 30 秒后自动取消聚焦

### 颜色随滚动变化

行星核心颜色在 Act 1→Act 3 之间平滑过渡：

- Act 1（暗色海洋）：冷白 `#f0f8ff`
- Act 2（白化过渡）：逐步过渡
- Act 3（内容阶段）：灰蓝 `#64748b`

光晕颜色不随滚动变化。

## 4. 视觉变化时机

| 事件 | CentralStar | Planets |
|------|:---:|:---:|
| 页面加载（Act 1） | 不可见 | 不可见 |
| 滚入 Act 3（sp ≥ 85%） | 渐进出现（smoothstep） | 渐进出现（smoothstep） |
| 滚动（Act 3 内） | 光晕脉冲持续 | 颜色细微变化 + 光晕脉冲 |
| 点击行星聚焦 | 无变化 | 非聚焦行星光晕淡出 |
| day/night 切换 | 无变化（不受主题影响） | 无变化（不受主题影响） |

> **注意**：CentralStar 和 Planets 的光晕效果不受 day/night 主题切换影响——它们在 3D 场景中渲染，主题系统仅影响 CSS 层和 Terminal 颜色。

## 5. 故障排除

### Q: Act 3 中看不到行星光晕？

- 滚动到 90%+ 确保 `smooth3` 接近 1.0
- 检查 `INNER_GLOW_SCALE` 是否设为有效值（> 1.0）
- 检查 `INNER_GLOW_OPACITY` 是否 > 0

### Q: 光晕太暗/太亮？

- 调整对应组件的 `*_OPACITY` 常量
- 调整 `*_SCALE` 控制扩散范围
- 见 [`maintenance-guide.md`](./maintenance-guide.md) 调参指南

### Q: Fresnel 辉光不明显？

- 尝试从侧面观察行星（旋转视角）
- 降低 `AtmosphereShader.ts` 中的 `pow(fresnel, 2.0)` 指数（辉光更宽）
- 增加 `ATMOS_SHELL_OPACITY`

### Q: 光晕消失/闪烁？

- 聚焦状态会淡出非聚焦行星，检查是否有行星被点击
- 检查 `useFrameCache` 是否跳帧
