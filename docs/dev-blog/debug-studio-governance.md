# Debug Studio 治理与验收记录

日期：2026-09-08。本文记录本轮治理的背景、实现与一次验收结果；当前操作入口见 [Debug Studio](../../src/debug/README.md)。

## 已处理的问题

原界面的全局 Leva 面板会挤占三栏工作区；不同尺寸、原点的模型缺少统一取景；GLTF 缓存对象被多 Canvas 重复挂载，导致对比视口丢失模型。相机数值、自动旋转、场景树、性能统计及截图保存也存在未接线或说明与实现不一致的问题。

本轮按工作区、交互状态、图标制作和可维护性四部分完成治理：

- 将局部 Leva 面板纳入右侧页签，侧栏可收起、拖动和键盘调整；窄窗口默认收起覆盖式侧栏。
- 模型按局部包围盒归一化，并按投影边界自动取景；各视口独立克隆节点、骨骼与材质，共享缓存几何体和贴图。
- 加载完成后生成对象树，按稳定路径同步选择、隐藏与隔离；相机数值、对比联动和自动旋转接入实际视口。自动旋转显式请求下一帧，保持静止时的 demand 渲染。
- 图标编辑共用主页烘焙函数，补全实际预览、日夜效果、保存、重新读取、默认草稿与失败反馈。
- 视口导出显式离屏渲染，支持活动视口/拼图、透明背景、辅助对象和结果预览；统计来自活动视口的真实 render。
- 修复共享烘焙函数误释放源模型几何体/材质的问题，增加独立灯塔模式隔离主页滚动行为。
- 统一前后端保存校验，使用主入口专用的配置更新事件，避免保存后重载 Studio。重写相关 README、操作及维护说明，移除未使用的相机/面数注册表元数据。

架构依据与资源所有权说明见 [维护指南](../../src/debug/MAINTENANCE.md)，其中引用 R3F 和 Three.js 官方文档。

## 验证边界

当前注册模型没有用于本轮验收的动画片段，尚未使用真实含动画 GLB 做播放/暂停的视觉验收。动画控制仅在资源提供片段时出现。浏览器检查在 Codex 内置浏览器进行，未覆盖全部浏览器和显卡组合。性能显示反映当前视口实际渲染活动，不作为跨设备性能基准。

主应用仍维持原有三幕、Canvas flat/demand 和主题边界；本轮对共享灯塔与烘焙改动进行了首幕及主题/滚动回归，未做所有行星外部链接和全部终端命令的全面回归。
