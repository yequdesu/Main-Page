## 种子与组成

正文先区分整束几何、丝线内外换代与单条沿线绘制三个层次，再介绍生成和消退；普通局部重组与 CME 外流不共用退场分支。完整机制对照见[模型总览](../../../docs/stellar-plasma-model.md#先读三条演化路径)。左右退场读数说明目标间隔的种子随机取样、事件尾部限制与重放规则。

支持 `?type=nested&seed=0.47&t=2.5`；类型须为共享注册表的六种标识之一，种子为 `[0, 1)` 的十进制数，时间范围为 0–36 秒。无效 URL 参数回退到默认值；表单无效值提示错误并保留现有结果。预设、随机与手动输入使用同一生成入口，复制链接包含类型、种子和时间。

图鉴复用 [stellarMorphology.ts](../../behaviors/stellarMorphology.ts) 与 [stellarPlasma.ts](../../behaviors/stellarPlasma.ts)。嵌套拱廊和低矮环簇必须绑定另一种类型；结果中的 `companion` 和 `sourceKind` 用于展示组合及每个环系的归属。两类可以相互伴随，不能用增加同类型数量代替。模型规则、公式与适用边界见[日珥降阶模型](../../../docs/stellar-plasma-model.md)。

SVG 卡片直接投影模拟第 8 秒的路径表；三维预览默认也暂停于第 8 秒。支持 0.35×、1×、2× 播放，阶段按钮覆盖初生、生长、稳定、松弛、回缩与结束。复制链接重放类型、种子、时间和默认正视图，不保存拖动后的相机。六类卡片随种子重新积分一次，播放时不重算卡片。

生命周期公式由 [stellarLifecycle.ts](../../behaviors/stellarLifecycle.ts) 提供，[stellarReorganization.ts](../../behaviors/stellarReorganization.ts) 为各环系生成独立时序、弱背景磁通配置和条件重组方案。SVG 包络表示原有环系的几何高度，在交接完成处截止；[Redraw.tsx](Redraw.tsx) 与生产模型共用 [stellarRedraw.ts](../../behaviors/stellarRedraw.ts) 的出生表，展示丝线代数、方向箭头、绘入/擦除前沿、数量上限与最短生长间隔。点击“下一条新丝线”查看槽位回收和新代接入；生长向外补入、稳定期暂停、消退向内补入。SVG 为更新规则示意，不是实际投影；勾选“显示丝线层次”查看三维路径的内外顺序，开关仅改变着色。

普通环系自然消退为 12–15.6 秒，CME 残留拱廊的主要回缩约 4.4 秒；这不是所有真实事件的统一比例。条件重组先用 0.30 秒预生长，再用 0.65 秒按层次启动、沿弧长交接；旧主环完全退出。中央过渡环交错保留约一半丝线，两侧保持完整数量；中央接住原拱顶，停留 0.12 秒后每隔 0.12 秒由外向内启动一条丝线，每条回落 0.40 秒、沿方向擦除 0.40 秒；两侧短环用 0.28 秒转向低拱平衡轮廓，随后各自鼓胀与回落，先退场侧由种子决定，另一侧延后且较慢回落，完整退场常规相差 1.00–1.55 秒（受事件剩余时间限制）；高度、拱肩宽度和偏斜共同响应，每侧的整束形变由自己的种子驱动；几何不按层次排队，仅沿线擦除每隔 0.18 秒启动下一条，退场窗口为 0.38 秒。按钮可跳至向内更迭、预生长、交接、中央承接/回落、分支分离、中央逐条退场、振荡上抬、错峰回落和重组结束，避免把短环退场一并压缩到交接窗口。三支在预生长、交接、回落和退场时共用弯曲空间走廊，邻接拱足固定在同一区域内的不同位置；最终路径保留高度与纵深，在分隔面附近调整横向轮廓。常量见 `LOCAL_RECONNECTION`；本页事件为 36 秒，主页为 30–38 秒。左右短环复用 [stellarShortLoop.ts](../../behaviors/stellarShortLoop.ts) 的形变响应与轮廓采样，中央继续使用原有较弱响应。SVG 分别展示左右目标与实际拱顶高度、不规则脉冲时刻与方向，以及同一时刻的两侧参考轮廓；可跳至左右鼓胀、左右回落、错峰对照和回落末段。每侧 3–5 次脉冲及初始回弹方向由种子生成；响应表允许任意年龄读取，主等离子体模拟在 seek 回退时仍需重建后重放。丝线换代仍是发光结构的艺术近似；公式见[非对称生命周期](../../../docs/stellar-plasma-model.md#足点锚定的非对称生命周期)。

弧长实验复用 [stellarShortLoop.ts](../../behaviors/stellarShortLoop.ts) 的耦合响应。断裂初期左支向左、右支向右激发；基础横向刚度为原始值的 25%，朝外推力增益 2.40、持续 0.20–0.28 秒。参考拱顶可以靠近外侧足点，高度与横摆共享弧长张力；20% 指相对参考弧长的变化，不是拱顶位移。消退时参考弧长趋近固定足点间距，各方向振荡共同收拢。原有错峰回落、两腿迟滞、种子脉冲与丝线擦除时序继续保留。

[Recoil.tsx](Recoil.tsx) 增加相对弧长变化 SVG，与横向位移、上下响应及参考轮廓共读同一事件年龄。参考图使用统一高宽比 0.45，不包含实际交接外肩与空间走廊；“未耦合周期”只描述基础横向弹簧，不能当作完整响应的实际周期。按钮可跳到激发、首次偏摆、反向回摆和各侧回落，并在三维预览中慢速播放。“单侧留存”按钮跳到先退场侧完全消失后 0.08 秒；读数分别显示两侧回落用时和完整退场时刻。

[Preview.tsx](Preview.tsx) 在原有时间回报节奏（约 0.1 秒一次）读取资产的 `getShortLoopDiagnostics()`，不新增时钟。预览下方“当前三维弧长校验”显示最终三维曲线的平均弧长、参考值、全束最大偏差和整束约束修正比例；数据已包含交接、形变和邻接分离。统计检查包括几何存在但正在擦除的丝线，避免可见度掩盖超限。正文公式与方法边界见[模型手册](../../../docs/stellar-plasma-model.md#重组短环的过冲与阻尼振荡)。

## 渲染与生命周期

采用 `flat`、`frameloop="demand"` 和正交相机。换种子、时间回退、诊断开关与视角变动请求新帧；播放中由 `useFrame` 推进并调用 `invalidate()`，暂停时停止连续请求。Drei OrbitControls 响应拖动/缩放并请求渲染。页面隐藏或预览离开视口时暂停，返回后需手动播放。没有额外 RAF 或定时器。依据：[R3F 按需渲染](https://r3f.docs.pmnd.rs/advanced/scaling-performance)、[invalidate API](https://r3f.docs.pmnd.rs/api/hooks)。

预览拥有一个 [stellarActivity](../../actors/assets/stellarActivity.ts) 实例，仅开启首个日珥通道。使用工厂的 `layoutLocal()` 在局部切平面绘制，复用现行发光材质、物质团块及共享路径表；其余通道透明度保持为零。常规 `layout()` 可恢复主页日面坐标。种子/类型变化或时间回退只重建 CPU 模拟，保留 GPU 纹理对象；卸载释放该实例的几何体、材质、路径及重绘纹理。旋转控制与磁通区域标记由 R3F/Drei 管理。发生重组的种子从初始时刻就标出 C、D 两个弱背景区域；卡片仍仅显示原有主体环系，分类描述初始构型，不强制退场保持同一拓扑。

新增类型时同步更新共享注册表、模型约束与本文案；图鉴不要另写一套 SVG 几何曲线；代际示意应继续调用共享出生表、方向及沿线绘制进度。验证覆盖种子、组合、初态回退与资源释放；视觉修改还需检查桌面/窄屏的预览、表单、播放、切换视角、足点与卡片。

## 几何约束说明

正文列出约束的作用对象与边界；完整坐标约定、软限制、最终检查及执行顺序集中维护在[几何约束总览](../../../docs/stellar-plasma-model.md#几何约束总览)。左右短环的最终弧长保护从交接开始启用，不能泛化到中央支、普通主环或 CME；同侧整束共用修正系数，空间走廊在修正后再次应用。几何测试覆盖有限样本，不等同于全场无交叉或完整磁场守恒的证明。
