# Debug Studio 操作手册

使用 `pnpm dev` 后访问 `/debug.html`；也可用 `pnpm debug` 将根路径直接指向工作台。需要同时观察主页图标时使用 `pnpm dev`。

## 查看与比较模型

1. 顶部选择灯塔、中央恒星、单颗行星、Voyager 1 或低模版本。加载结束后模型自动居中，左侧显示真实对象层级。
2. 使用“单视图”“对比”或“四视图”。对比的右侧始终使用独立线框材质；四视图含三个固定方向的正交相机。
3. 拖动旋转透视视口，滚轮缩放；正交视口保持观察方向，可平移和缩放。点击视口标题可指定活动视口。
4. “适配全部”保留各视口方向并完整取景；“重置视角”恢复默认方向。改变模型变换后可再次适配。
5. 场景页签的距离、方位角、仰角直接控制活动透视相机。“对比视口相机联动”同步交互结束后的姿态及数值编辑；自动旋转期间相机数值禁用。

同一页面内切换模型会保留各模型的场景参数、选择/隐藏/隔离状态及相机姿态。刷新页面会清除这些会话状态。模型自带动画仅在有片段时显示，播放状态不会在切换模型时继续。

## 查看恒星与单颗行星

“中央恒星 · 程序化资产”显示核心、内层光晕及近场/远场柔光；“单颗行星 · 程序化资产”显示一个行星核心、大气层与光晕。主页三颗行星使用同一视觉模型，工作台预览不加入轨道、公转或标签。无需先访问或滚动主页。

两者默认暂停。在右侧“对象”页签的“预览动画”中点击“播放”，可调整速度或暂停光晕呼吸；“停止”恢复初始时刻。停止后重新选择片段再播放。切换对比或四视图时，各视口使用同一播放时间。行星使用固定预览尺寸，便于比较形体和材质。

左侧行星下的 `planet_0`、`glow_0`、`atmos_0`、`halo_0` 分别为核心、内层光晕、大气层和外围 Sprite；选择核心后“聚焦”可近看球面及线框。隐藏或隔离在播放期间也有效。恒星默认按核心和近场柔光取景，远场渐变仍渲染；行星按包含光晕的范围取景。PNG 导出沿用当前显示状态和已渲染姿态。

## 场景与对象

场景页签提供摄影棚、夜间、清晨、日落灯光预设，采用本地灯光，无需下载 HDR 环境贴图。预设调整环境光倍率和默认主/补光颜色；自行指定光色后保留该颜色。

网格、坐标轴、整个模型包围盒和线框各有一个开关。选中对象另有青色边界，作用于所有视口。

左侧搜索名称或类型，点击节点名称选中，点击箭头展开。也可直接点击视口中的模型对象。选中后：

- “聚焦”将所有视口取景到该对象。
- “隐藏 / 显示”切换所选节点及子树的可见性。
- “隔离”只显示该对象子树，再次点击取消。
- “显示全部对象”清除隐藏和隔离设置。

对象页签提供来源与只读材质属性，包含多材质 Mesh；该面板不编辑或保存材质。GLB 存在动画时可选择片段、播放/暂停、停止以及调整速度。

## 导出视口 PNG

点击顶部“导出 PNG”，在右侧选择：

- 活动视口，或当前布局的全部视口拼图。
- 1280 × 800、1920 × 1200、2560 × 1600。
- 透明背景，是否包含网格、坐标轴和包围框。

点击“下载 PNG”。拼图顺序与屏幕一致：四视图为正视、侧视、顶视、透视。导出保留相机方向与对象显示状态，按目标尺寸重新渲染；比例不同会改变取景范围。线框视口的模型线框属于模型渲染，不受“包含辅助线框”开关影响。

## 制作灯塔图标

1. 选择灯塔，打开“灯塔图标”页签；编辑器读取已保存 YAML，缺失字段使用默认值。
2. 调整图标专用参数，稍后观察实际 PNG 和品牌效果。图标相机/灯光与工作台场景参数分别管理。
3. 切换日间、夜间预览。日间固定取消描边，填充色与主页使用相同主题值。
4. “保存配置”将允许保存的字段写入 YAML，成功后显示同步状态；已打开的主页刷新图标，Studio 保留当前视口和编辑状态。
5. “重新加载”放弃当前图标草稿，读取磁盘配置；“恢复默认”只替换本地草稿，需点击保存才更新文件。
6. “下载图标 PNG”导出当前预览。最终宽度为所设宽度加 400px 基线延伸。

修改后会显示未保存提示；刷新或关闭页面时浏览器可提示离开。保存失败会显示错误并保留草稿。预览分辨率和抗锯齿只影响本次预览，不会产生待保存状态。

## 布局与状态

两侧栏可通过顶部按钮收起，分隔条支持拖动和键盘左右键。窄窗口默认收起侧栏，展开后使用覆盖式布局，同一时间打开一侧。

底栏显示活动视口的实际渲染统计，Draw Calls 和三角面数包含当前显示的辅助对象。静止时使用按需渲染，显示空闲状态；自动旋转或动画播放时才持续产生帧数。这里不是显示器刷新率或显卡基准测试。
